# Gerenciador de Tarefas do Windows

O Gerenciador de Tarefas é uma ferramenta do Windows usada para monitorar e controlar processos em execução.

Ele permite visualizar o uso de recursos do sistema.

## Como abrir

Métodos comuns:

Ctrl + Shift + Esc

ou

Ctrl + Alt + Del

## Principais abas

### Processos

Mostra todos os programas em execução.

Exibe informações como:

- uso de CPU
- uso de memória
- uso de disco
- uso de rede

### Desempenho

Exibe gráficos do uso de recursos do sistema:

- CPU
- memória
- disco
- rede

### Inicializar

Mostra programas que iniciam automaticamente com o Windows.

Permite desativar programas que deixam o sistema lento.

### Usuários

Mostra os usuários logados no sistema.

### Detalhes

Exibe processos com mais informações técnicas.

## Importância

O Gerenciador de Tarefas é uma ferramenta essencial para:

- diagnóstico de problemas
- identificação de processos que consomem muitos recursos
- finalização de programas travados
