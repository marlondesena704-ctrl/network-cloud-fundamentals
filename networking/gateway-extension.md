# Gateway

Gateway é um dispositivo que conecta redes diferentes.

Ele funciona como ponto de saída de uma rede.

## Exemplo prático

Em uma rede doméstica:

Computador → Roteador → Internet

O roteador atua como gateway.

## Gateway padrão (Default Gateway)

É o endereço IP usado pelos dispositivos para acessar redes externas.

Exemplo:

192.168.1.1

Quando um dispositivo precisa acessar um site na internet, ele envia os dados para o gateway.

## Importância

Sem um gateway:

- dispositivos só conseguiriam se comunicar dentro da mesma rede local.
