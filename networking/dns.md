# DNS (Domain Name System)

DNS é o sistema responsável por traduzir nomes de domínio em endereços IP.

Ele funciona como uma "agenda telefônica" da internet.

## Problema que o DNS resolve

Computadores se comunicam através de endereços IP.

Exemplo:

142.250.190.78

Mas para humanos é mais fácil usar nomes como:

google.com

O DNS faz essa tradução.

## Como funciona o processo

Quando um usuário digita um domínio no navegador:

1. O computador consulta o servidor DNS
2. O DNS procura o endereço IP correspondente
3. O servidor retorna o IP
4. O navegador acessa o servidor correto

## Tipos de servidores DNS

### DNS Recursivo

Responsável por buscar a resposta para o cliente.

### DNS Autoritativo

Possui a informação oficial do domínio.

## Importância do DNS

Sem DNS seria necessário memorizar endereços IP de todos os sites.

DNS é um dos pilares da internet.
