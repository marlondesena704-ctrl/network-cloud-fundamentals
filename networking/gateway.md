# Gateway em Redes de Computadores

Um gateway é um dispositivo ou sistema que conecta duas redes diferentes.

Ele funciona como um ponto de entrada ou saída para comunicação entre redes.

## Função principal

Permitir que dispositivos de uma rede se comuniquem com dispositivos de outra rede.

## Exemplo comum

Em redes domésticas ou empresariais, o **roteador** normalmente atua como gateway.

Ele conecta:

Rede local (LAN)

com

Internet (WAN)

## Gateway padrão (Default Gateway)

O gateway padrão é o endereço usado pelos dispositivos para acessar outras redes.

Exemplo:

Computador → envia tráfego → gateway → internet

## Importância

Sem um gateway, dispositivos de uma rede local não conseguiriam acessar redes externas.

## Uso em infraestrutura

Gateways são usados em:

- roteadores
- firewalls
- redes corporativas
- ambientes cloud
