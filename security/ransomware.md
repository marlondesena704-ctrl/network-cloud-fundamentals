# Ransomware

Ransomware é um tipo de malware que sequestra dados do usuário.

Ele criptografa arquivos e exige pagamento para liberá-los.

## Funcionamento

1. O malware infecta o sistema
2. Arquivos são criptografados
3. Uma mensagem exige pagamento (resgate)

O pagamento geralmente é solicitado em criptomoedas.

## Impacto

Ransomware pode causar:

- perda de dados
- interrupção de serviços
- prejuízos financeiros

## Exemplos famosos

- WannaCry
- NotPetya

## Prevenção

- realizar backups frequentes
- manter sistemas atualizados
- evitar abrir anexos suspeitos
- utilizar antivírus e firewall

## Importância da segurança

Empresas utilizam várias camadas de segurança para evitar ataques desse tipo.
