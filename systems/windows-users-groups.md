# Usuários e Grupos no Windows

O Windows permite gerenciar diferentes usuários e permissões dentro do sistema.

Isso é essencial para ambientes corporativos.

## Usuários

Usuários representam contas que podem acessar o sistema.

Cada usuário possui:

- login
- senha
- permissões específicas

## Tipos de usuários

### Administrador

Possui acesso completo ao sistema.

Pode:

- instalar programas
- modificar configurações
- gerenciar outros usuários

### Usuário padrão

Possui acesso limitado.

Não pode modificar configurações críticas do sistema.

## Grupos

Grupos são conjuntos de usuários com permissões semelhantes.

Exemplo:

- Administradores
- Usuários
- Convidados

## Vantagens do uso de grupos

- simplifica gerenciamento de permissões
- facilita administração de sistemas grandes
- aumenta segurança

## Uso em redes corporativas

Em ambientes empresariais, usuários e grupos são frequentemente gerenciados por:

- Active Directory
