# Active Directory

Active Directory (AD) é um serviço de diretório desenvolvido pela Microsoft para gerenciar redes corporativas.

Ele permite controlar usuários, computadores e recursos dentro de uma organização.

## Função principal

Centralizar a administração da rede.

Com o Active Directory é possível:

- gerenciar usuários
- controlar permissões
- aplicar políticas de segurança
- autenticar usuários na rede

## Componentes principais

### Domain Controller (DC)

Servidor responsável por armazenar o banco de dados do Active Directory.

Ele realiza autenticação de usuários e dispositivos.

### Domínio

Conjunto de computadores e usuários gerenciados pelo Active Directory.

### Unidade Organizacional (OU)

Estrutura usada para organizar usuários e computadores dentro do domínio.

### Group Policy (GPO)

Políticas aplicadas automaticamente a usuários ou computadores.

Exemplos:

- bloquear acesso a configurações
- instalar programas automaticamente
- aplicar regras de segurança

## Uso em empresas

Active Directory é amplamente usado em ambientes corporativos para:

- controle de acesso
- autenticação centralizada
- administração de redes Windows
