# Processador (CPU)

O processador, também chamado de CPU (Central Processing Unit), é o principal componente responsável por executar instruções e realizar cálculos no computador.

Ele é considerado o "cérebro" do sistema.

## Funções do processador

O processador executa três funções principais:

1. Buscar instruções na memória
2. Decodificar essas instruções
3. Executar as operações necessárias

Esse ciclo é chamado de **Ciclo de Instrução**.

## Componentes principais da CPU

### Unidade de Controle (CU)

Responsável por coordenar as operações do processador e controlar a execução das instruções.

### Unidade Lógica e Aritmética (ALU)

Realiza operações matemáticas e lógicas, como:

- soma
- subtração
- comparação de valores

### Registradores

Memória extremamente rápida dentro da CPU usada para armazenar dados temporários.

## Clock do processador

O clock define a velocidade com que o processador executa operações.

É medido em:

- GHz (Gigahertz)

Quanto maior o clock, maior a capacidade de processamento (em geral).

## Núcleos (Cores)

Processadores modernos possuem múltiplos núcleos.

Exemplo:

- Dual Core
- Quad Core
- Octa Core

Cada núcleo pode executar tarefas simultaneamente.

## Importância em servidores

Em ambientes de infraestrutura e cloud, CPUs são essenciais para:

- virtualização
- processamento de aplicações
- bancos de dados
- containers
