# Linux

Linux é um sistema operacional de código aberto baseado no kernel Linux.

Ele é amplamente utilizado em servidores, infraestrutura de rede, cloud computing e ambientes de desenvolvimento.

## Origem do Linux

O kernel Linux foi criado em 1991 por Linus Torvalds.

Ele foi inspirado no sistema operacional Unix.

Hoje o Linux é mantido por uma grande comunidade global de desenvolvedores.

## Distribuições Linux

Linux não é um único sistema operacional completo.

Existem diversas distribuições (distros), que são versões do Linux com diferentes ferramentas e interfaces.

Exemplos:

- Ubuntu
- Debian
- Fedora
- Arch Linux
- CentOS

## Componentes de um sistema Linux

### Kernel

O kernel é o núcleo do sistema operacional.

Ele controla:

- hardware
- memória
- processos
- dispositivos

### Shell

Interface de linha de comando usada para interagir com o sistema.

Exemplo:

- Bash

### Sistema de arquivos

Linux organiza arquivos em uma estrutura hierárquica.

Exemplo de diretórios importantes:

/home  
/etc  
/bin  
/var

## Por que Linux é usado em servidores?

Linux é amplamente utilizado em infraestrutura porque oferece:

- alta estabilidade
- segurança
- flexibilidade
- baixo consumo de recursos
- software open source

## Uso em Cloud

Grande parte dos servidores em cloud utilizam Linux.

Exemplos:

- servidores web
- containers
- Kubernetes
- bancos de dados
