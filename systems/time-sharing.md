# Sistema de Tempo Compartilhado (Time Sharing)

O sistema de tempo compartilhado permite que vários usuários utilizem um mesmo computador simultaneamente.

Isso é possível através da divisão do tempo de processamento da CPU.

## Como funciona

O sistema operacional alterna rapidamente entre os processos de diferentes usuários.

Cada processo recebe uma pequena fração de tempo da CPU.

Esse processo é chamado de **time slice**.

## Objetivo

Permitir que vários usuários utilizem um sistema sem perceber atrasos significativos.

## Características

- múltiplos usuários
- múltiplos processos
- gerenciamento eficiente da CPU
- alternância rápida entre tarefas

## Uso em servidores

Sistemas de tempo compartilhado são fundamentais em:

- servidores Linux
- sistemas multiusuário
- ambientes de cloud computing

Isso permite que diversos serviços e usuários utilizem o mesmo servidor ao mesmo tempo.
