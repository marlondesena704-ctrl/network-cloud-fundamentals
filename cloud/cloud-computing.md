# Cloud Computing

Cloud Computing é um modelo de computação onde recursos de TI são disponibilizados pela internet.

Esses recursos podem incluir:

- servidores
- armazenamento
- bancos de dados
- redes
- softwares

## Como funciona

Em vez de possuir infraestrutura física local, empresas utilizam servidores em data centers de provedores de nuvem.

Esses recursos são acessados remotamente.

## Principais provedores de cloud

- AWS (Amazon Web Services)
- Microsoft Azure
- Google Cloud

## Vantagens da computação em nuvem

### Escalabilidade

Recursos podem ser aumentados ou reduzidos conforme a demanda.

### Alta disponibilidade

Infraestruturas distribuídas reduzem risco de falhas.

### Redução de custos

Não é necessário investir em hardware próprio.

### Acesso remoto

Serviços podem ser acessados de qualquer lugar.

## Uso em infraestrutura

Cloud é amplamente utilizada para:

- hospedagem de aplicações
- armazenamento de dados
- execução de máquinas virtuais
- serviços de rede
