# Servidor Proxy

Um proxy é um servidor intermediário entre o usuário e a internet.

Ele recebe solicitações do cliente e as encaminha para o servidor de destino.

## Funcionamento

Fluxo de comunicação:

Cliente → Proxy → Internet

O proxy pode:

- encaminhar requisições
- armazenar cache
- filtrar conteúdo
- registrar acessos

## Tipos de proxy

### Forward Proxy

Utilizado por clientes para acessar a internet.

Muito usado em redes corporativas.

### Reverse Proxy

Fica na frente de servidores web.

Ele recebe requisições da internet e encaminha para os servidores internos.

Exemplo:

- balanceamento de carga
- proteção de servidores

## Vantagens

- controle de acesso à internet
- aumento de segurança
- cache de conteúdo
- anonimização de conexões

## Uso em infraestrutura

Proxies são muito utilizados em:

- redes corporativas
- firewalls
- sistemas de segurança
- arquiteturas cloud
