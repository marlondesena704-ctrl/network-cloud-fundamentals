# Tipos de Cloud Computing

Existem diferentes modelos de implantação de nuvem.

## Nuvem Pública

Infraestrutura pertencente a um provedor de cloud e compartilhada entre diversos clientes.

Exemplos:

- AWS
- Azure
- Google Cloud

### Vantagens

- baixo custo inicial
- alta escalabilidade
- manutenção realizada pelo provedor

---

## Nuvem Privada

Infraestrutura dedicada a uma única organização.

Pode ser hospedada:

- no próprio data center
- em provedor especializado

### Vantagens

- maior controle
- maior segurança

---

## Nuvem Híbrida

Combina nuvem pública e privada.

Exemplo:

- dados sensíveis em cloud privada
- aplicações em cloud pública

Esse modelo é comum em empresas que precisam equilibrar segurança e escalabilidade.

---

## Benefícios da cloud

- flexibilidade
- escalabilidade
- disponibilidade
- redução de custos operacionais
