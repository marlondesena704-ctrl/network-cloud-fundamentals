# VPN (Virtual Private Network)

VPN significa Virtual Private Network (Rede Privada Virtual).

Ela permite criar uma conexão segura entre um dispositivo e uma rede através da internet.

## Como funciona

Uma VPN cria um **túnel criptografado** entre o usuário e o servidor VPN.

Fluxo de conexão:

Usuário → Internet → Servidor VPN → Rede de destino

Isso protege os dados durante a transmissão.

## Principais objetivos

- aumentar segurança
- proteger dados
- permitir acesso remoto a redes privadas

## Tipos de VPN

### VPN de acesso remoto

Permite que um usuário se conecte à rede de uma empresa remotamente.

Muito usado em:

- home office
- acesso remoto a servidores

### VPN site-to-site

Conecta duas redes diferentes através da internet.

Exemplo:

Filial ↔ Matriz

## Benefícios

- criptografia de dados
- proteção em redes públicas
- acesso seguro a sistemas internos

## Uso em infraestrutura

VPNs são usadas em:

- redes corporativas
- acesso remoto a servidores
- ambientes cloud
