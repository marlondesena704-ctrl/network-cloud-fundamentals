# Fundamentos de Redes de Computadores

Uma rede de computadores é um conjunto de dispositivos conectados entre si para compartilhar informações.

## Objetivos das redes

- compartilhar arquivos
- compartilhar impressoras
- acessar internet
- comunicação entre sistemas

## Componentes de uma rede

### Dispositivos

- computadores
- servidores
- roteadores
- switches

### Meios de transmissão

- cabos de rede
- fibra óptica
- conexões sem fio

### Protocolos

Protocolos são regras que definem como a comunicação acontece.

Exemplo:

- TCP/IP
- HTTP
- FTP

## Tipos de rede

### LAN

Rede local utilizada em casas ou empresas.

### WAN

Rede de longa distância.

Exemplo: internet.

### MAN

Rede metropolitana.

## Importância

Redes são a base da infraestrutura moderna de TI.

Elas permitem:

- comunicação global
- acesso a serviços cloud
- funcionamento de aplicações distribuídas
