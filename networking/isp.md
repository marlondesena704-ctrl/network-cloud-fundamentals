# Provedor de Internet (ISP)

ISP significa Internet Service Provider.

É a empresa responsável por fornecer acesso à internet para usuários e empresas.

## Funções de um ISP

- fornecer conexão à internet
- atribuir endereços IP
- gerenciar infraestrutura de rede
- conectar usuários à internet global

## Exemplos de ISPs

- operadoras de telecomunicação
- provedores regionais de internet

## Tecnologias utilizadas

Provedores utilizam diferentes tecnologias para conectar usuários:

- fibra óptica
- cabo
- rádio
- satélite

## Infraestrutura

ISPs possuem:

- data centers
- roteadores de alta capacidade
- redes de backbone

## Importância

Sem provedores de internet não seria possível conectar usuários à rede mundial.
