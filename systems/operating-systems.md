# Sistemas Operacionais

Um sistema operacional é o software responsável por gerenciar os recursos do computador e permitir a interação entre o usuário e o hardware.

## Funções do sistema operacional

- gerenciar processos
- controlar memória
- administrar armazenamento
- controlar dispositivos de hardware
- fornecer interface para usuários

## Exemplos de sistemas operacionais

### Windows

Muito utilizado em computadores pessoais e ambientes corporativos.

### Linux

Muito utilizado em servidores, cloud e infraestrutura.

### macOS

Sistema operacional da Apple para computadores Mac.

### Android

Sistema baseado em Linux usado em dispositivos móveis.

## Componentes principais

### Kernel

Núcleo do sistema operacional responsável por controlar o hardware.

### Sistema de arquivos

Organiza como os dados são armazenados no disco.

### Interface do usuário

Pode ser:

- interface gráfica (GUI)
- linha de comando (CLI)

## Importância em servidores

Em ambientes de infraestrutura, sistemas operacionais como Linux são amplamente usados para executar:

- servidores web
- bancos de dados
- aplicações
