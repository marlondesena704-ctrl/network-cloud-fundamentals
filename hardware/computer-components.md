# Componentes de um Computador

Um computador é composto por diversos componentes de hardware que trabalham juntos para executar tarefas.

## Principais componentes

### Processador (CPU)

Responsável por executar instruções e realizar cálculos.

### Memória RAM

Armazena temporariamente dados e programas em execução.

### Armazenamento

Dispositivos como HD e SSD armazenam dados permanentemente.

### Placa-mãe

Conecta todos os componentes do computador.

### Fonte de alimentação

Fornece energia para todos os componentes.

### Dispositivos de entrada

Exemplos:

- teclado
- mouse
- scanner

### Dispositivos de saída

Exemplos:

- monitor
- impressora
- alto-falantes
