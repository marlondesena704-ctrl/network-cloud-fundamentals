# Arquiteturas CISC e RISC

Processadores utilizam diferentes arquiteturas de conjunto de instruções.

As duas principais são:

- CISC
- RISC

## CISC (Complex Instruction Set Computer)

Possui um conjunto grande e complexo de instruções.

### Características

- muitas instruções diferentes
- instruções mais complexas
- execução pode levar mais ciclos

### Exemplo

Processadores x86 utilizados em computadores tradicionais.

Exemplos de fabricantes:

- Intel
- AMD

## RISC (Reduced Instruction Set Computer)

Utiliza um conjunto menor e mais simples de instruções.

### Características

- instruções simples
- execução mais rápida
- maior eficiência energética

### Exemplos

Processadores utilizados em:

- smartphones
- tablets
- dispositivos embarcados

Arquiteturas comuns:

- ARM

## Comparação

CISC:

- instruções complexas
- maior compatibilidade
- muito usado em PCs

RISC:

- instruções simples
- alta eficiência
- comum em dispositivos móveis e servidores modernos

## Tendência atual

Muitos processadores modernos combinam características de ambas arquiteturas.
