# Switch em Redes de Computadores

Um switch é um dispositivo de rede usado para conectar vários dispositivos dentro de uma rede local (LAN).

Ele funciona na **camada 2 do modelo OSI (camada de enlace de dados)**.

## Função principal

Encaminhar dados entre dispositivos conectados à rede.

## Como funciona

O switch identifica dispositivos através de seus **endereços MAC**.

Ele mantém uma tabela chamada:

MAC Address Table

Essa tabela associa:

MAC Address → Porta do switch

Quando um pacote chega ao switch, ele verifica essa tabela para saber para qual porta enviar o pacote.

## Vantagens do switch

- reduz colisões de rede
- melhora desempenho da rede
- permite comunicação simultânea entre dispositivos

## Diferença entre switch e hub

Hub

- envia dados para todos os dispositivos

Switch

- envia dados apenas para o destino correto

## Uso em infraestrutura

Switches são usados em:

- redes corporativas
- data centers
- ambientes de cloud
